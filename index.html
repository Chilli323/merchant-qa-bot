📘 如何录入你自己的问答

所有问答都维护在文件顶部的 knowledgeBase 数组里。用记事本或任意编辑器打开本文件，找到 /* ===== 问答知识库（在此录入） ===== */ 这一段，照着格式增删即可。

每条问答的字段说明

  • id — 编号，唯一即可。
  • category — 分类，填 "调研表填写答疑" / "微信相关问题" / "支付宝相关问题" / "报错解答"（影响侧边栏筛选与标签颜色）。
  • question — 标准问法，机器人会拿它和用户输入做匹配。
  • keywords — 关键词数组，命中任意一个就加分。尽量把同义词、口语、错误码都列上。
  • answer — 回答内容，支持换行。插入图片用 [img:图片文件名]（图片放在同目录下）。
  • related（可选）— 关联问答的 id 数组，回答末尾会展示"相关问题"。

示例格式

{
  id: 101,
  category: "报错解答",
  question: "提示签名错误怎么办？",
  keywords: ["签名错误", "sign", "签名失败", "401"],
  answer: "1. 检查 API 密钥是否填写正确；\n2. 确认签名算法为 MD5；\n3. 参数需按字典序排序后再签名。",
  related: [102]
}

匹配机制（简单了解）

  • 同时计算「关键词命中」与「整句相似度」，综合打分。
  • 得分越高越靠前；低于阈值时机器人会列出最接近的几条供用户点选。
  • 所以 keywords 写得越全，识别越准。多写几种用户的口语问法。
